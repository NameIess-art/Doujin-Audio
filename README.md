# Doujin Audio

Doujin Audio 是一款面向 ASMR、同人音声与本地媒体库的 Android 音频播放器，采用 Flutter 构建界面，播放核心由 Android 原生 Media3 / ExoPlayer 驱动。应用将本地存储媒体、ASMR.ONE 在线流式内容与自定义播放队列统一置于多会话体系中管理。

当前版本以 [`pubspec.yaml`](pubspec.yaml) 为唯一版本源；正式安装包与版本更新均通过 GitHub Release 分发：[GitHub Latest Release](https://github.com/NameIess-art/Doujin-Audio/releases/latest)。

### 第一次使用

1. 下载对应架构或 universal 通用版 APK 并完成安装。若系统提示未知应用安装限制，请在系统设置中授权本应用安装应用包。
2. 进入“本地音频库”，通过系统文件夹选择器（SAF）添加曲库目录，或按需直接添加单文件/子文件夹。
3. 点击任意作品或音频条目即可开始播放。如需收听或下载在线资源，可在底部导航进入 ASMR.ONE 页面登录账号。

应用采用本地优先设计：本地媒体库索引、用户设置和播放状态完全存储在设备本地，网络请求仅发生在 ASMR.ONE 在线浏览、DLsite 元数据匹配与 GitHub 版本更新检查时。文件访问、通知与悬浮窗等权限均在使用对应功能时按需申请。

## 主要功能

### 播放控制与多会话管理

- **多会话播放体系**：支持同时维持多个独立的播放会话，卡片采用横向轮播视图；每个会话独立记录音轨、进度、音量、循环模式、字幕开关与音效配置。
- **自定义命名队列**：播放列表支持新建多个自定义命名的播放队列，可按名称、时长或添加时间排序，支持拖动卡片自由重排音频顺序、自定义卡片配色，并可选择是否允许同一作品的重复会话并存。
- **队列移除曲目保护**：从播放队列中移除当前正在播放的曲目时，正在播放的音频不会被突然掐断，而是平滑播放直至自然播完或用户手动切歌。
- **批量管理会话**：在播放列表长按进入多选模式，支持一键批量暂停、恢复播放或批量移除选中会话。
- **多维度播放范围**：提供 6 种播放模式——单曲循环、当前文件夹顺序播放、当前文件夹随机播放、跨文件夹顺序播放、跨文件夹随机播放，以及播完单曲立即停止的定时单次模式。
- **基础传输与定位**：包含播放/暂停、上一曲/下一曲、快退/快进（支持长按或双击步进）、微调进度滑块与播放失败快速重试。
- **紧凑进度条**：播放详情页进度条精简为 34px 紧凑布局，分段进度背景与时间打点标记动态垂直居中对齐。
- **加载与缓冲反馈**：在线音频或大型文件在载入或缓冲时，播放按钮动态显示转圈指示器，字幕区同步展示“加载中”提示；缓冲状态下仍支持点击切换播放状态或重新加载。
- **本地视频与纯音频切换**：
  - 音频条目对应为视频格式（MP4/MKV/WebM 等）时，播放详情页封面区域直接原生渲染视频画面。
  - 轻触视频画面可切换进入 AMOLED 纯黑沉浸式横屏全屏模式。
  - 支持息屏播放：关闭屏幕后视频自动转入后台纯音频流式播放。
  - 外观设置中支持开启“仅播放音频”，直接关闭视频画面渲染以节省电量与系统资源。

### 控制台与 DSP 音频增强

- **原生硬件均衡器 (EQ)**：自动识别设备底层音频芯片支持的物理频段，提供多种调音预设，支持手动微调各频段增益（dB），并支持新建、重命名、恢复默认及撤销删除自定义预设。
- **跳过静音 (Skip Silence)**：ExoPlayer 原生级检测并自动跳过音频流中无声的静音空白片段。
- **轻度降噪**：原生音频滤镜抑制背景白噪声与麦克风底噪。
- **动态音量平衡**：压制突发爆音并增强细微呼吸声与弱音，平稳整体听感。
- **声道互换与平衡**：支持左右声道一键反转，支持在 -1.0 至 +1.0 之间自由微调声场中心，适配偏音耳机或单耳佩戴场景。
- **变速播放**：支持 0.25x 至 3.0x 范围内的无级变速与音高保持，提供快捷倍速挡位预设与连续微调滑块。
- **时间段打点与片段循环**：可在任意音频时间节点打点标记并命名，支持分配不同标识颜色；可限定特定时间区间进行单片段循环播放。
- **功能状态角标**：详情页右上角、播放列表卡片以及底部迷你播放条均能直观展示当前会话已激活的音频特性角标（如 EQ、降噪、静音跳过、倍速、声道平衡等）。

### 字幕系统

- **多格式支持**：兼容 `.srt`、`.ass`、`.ssa`、`.vtt`、`.lrc` 字幕文件，支持同名文件自动加载或手动关联。
- **多端同步展示**：播放详情页卡片、底部紧凑播放胶囊与系统级悬浮窗口三端毫秒级实时同步当前字幕行。
- **系统全局悬浮字幕**：
  - 基于 Android `SYSTEM_ALERT_WINDOW` 权限，支持脱离应用界面在第三方应用上方悬浮展示。
  - 悬浮窗样式完全开放自定义：支持自由配置字体、字号、文字颜色、背景颜色、背景透明度与描边深度，设置页提供实时样式预览控件。
  - 悬浮窗支持在屏幕任意位置自由拖拽摆放并自动记忆贴边吸附位置。
- **全时间轴字幕浏览**：
  - 提供时间轴视图，支持上下滑动滚动浏览全文，自动高亮匹配当前播放进度。
  - 滑动浏览停止后平滑吸附回当前播放行；点击任意字幕行或定位按钮可直接让音频跳转至对应时间点。
- **错误与防抖优化**：
  - 音频解析失败或载入异常时，在字幕区域直接以红色文本呈现清晰错误详情。
  - 快进、快退或拖动进度条时应用内置平滑防抖阈值，淡入淡出呈现加载反馈，避免频繁闪烁。

### 本地媒体库与元数据管理

- **规范化目录与存储授权**：全面适配 Android Storage Access Framework (SAF)，持久化保持目录访问授权，应用重启或升级无需重复选权；同时兼容直接路径扫描与单文件导入。
- **层级文件树与多维分类浏览**：
  - 完整保留用户本地文件的文件夹层级结构，展开与折叠状态自动持久化记忆。
  - 支持按声优 (CV)、作品标签 (Tags)、时长、发售日期、添加时间与文件标题进行多维排序与分组。
  - 支持在列表中手动长按拖动自定义条目排序顺序。
- **原生分块扫描 (Chunked Scan)**：底层扫描任务采用原生分块事件机制，海量同人音声文件按批次增量提交写入数据库，避免一次性构造大型对象造成内存毛刺或界面卡顿。
- **检索与批量操作**：
  - 毫秒级即时多关键词模糊搜索。
  - 搜索结果页与媒体库列表均支持长按触发批量选择模式，方便一键批量添加至播放队列或执行批量管理。
- **智能封面匹配与提取**：
  - 采用多级分档图片解码（300px、600px、900px、1200px 及原图），兼顾滚屏流畅度与大图清晰度。
  - 智能扫描同级图片、提取音频内嵌 ID3/FLAC 封面图片，或从视频特定时间点抽取高清视频帧作为封面。
  - 设置中支持开启“优先使用音频内嵌封面”；详情编辑页支持手动从所有提取到的候选图库中点选封面。
  - 文件夹或文件更名后，封面缓存索引自动同步关联更新。
- **非破坏性元数据持久化**：
  - 运行时数据以 SQLite 为核心高速数据源，声优与标签使用有序关系表独立管理。
  - 采用目录内 `doujin-audio.json` 作为开放、通用的可移植元数据文件。
  - **严格非破坏性保障**：日常扫描、刷新列表、补齐时长或 RJ 编号时对已有 JSON 文件执行严格只读操作，绝不主动覆写或清空用户已有数据；仅当用户在作品详情页主动点按“保存”或确认导入 DLsite 数据时，应用才会执行原子更新，且完整保留已有 JSON 中的所有未知字段和第三方数据项。
  - 自定义挑选的封面（相对路径、内嵌图片缓存或视频帧截取数据）同步写入 `doujin-audio.json`，作品移出后重新导入时仍优先加载该选定封面。
- **安全移除与已移除目录管理**：
  - 从媒体库移出目录时提供带撤销倒计时的 Toast 提醒，防止误触操作。
  - 内置独立的“已移除目录”管理界面，已移出的路径持久化记录，后续扫描曲库时自动忽略该路径；用户可随时在管理界面中一键将其恢复回媒体库。
- **DLsite 元数据抓取与批量审查**：
  - 支持输入 RJ 编号、利用文件名或作品标题通过网络抓取 DLsite 官方元数据（包含作品名、声优、社团、发售日期、标签、封面等）。
  - 支持对媒体库未识别作品进行批量在线检索与自动匹配。
  - 提供专属的 DLsite 元数据审查页面：集成“上一部 / 下一部”作品切换导航条，支持逐部比对抓取结果、快速微调内容后再一键合并保存。

### ASMR.ONE 与下载管理

- **在线目录浏览与云端同步**：
  - 接入 ASMR.ONE 远程接口，支持按最新上架、流行排行、分类标签与声优检索作品。
  - 支持账号密码/凭据安全登录，云端实时双向同步用户收藏夹与播放历史。
  - 作品卡片支持滑动快速操作（播放、加至队列、查看详情），支持长按多选进行批量添加或下载。
- **在线流式播放与边播边存**：
  - 解析远程音频流直接挂载入本地多会话播放队列。
  - 可配置“播放后自动缓存”：播放完毕的音频自动保存至应用私有缓存目录，二次收听无需重复消耗流量。
- **后台下载与断点续传**：
  - 支持勾选单曲、子文件夹或整个作品打包下载至本地存储。
  - 下载目录通过 Android SAF 保持持久化授权。
  - 严格还原作品原始目录层级结构，并自动将封面另存为下载根目录下的 `Cover/<RJ号>.<扩展名>`，方便外部媒体播放器识别。
  - 任务调度机制：支持下载任务全局暂停、单独暂停、断点继续与失败重试；应用退至后台或进程退出前安全挂起任务，恢复后复用已下载临时分块继续传输。
  - 网络自愈与可调退避：单文件遭遇网络中断、响应截断或远端 5xx 错误时，自动执行指数退避重试（支持在 3 至 10 次之间配置重试次数限制，默认 5 次）；支持在 1 至 5 之间自定义同时并发下载的作品数量。
  - 数据安全保护：下载目录内预存的 `.json` 保持原始字节完全不变；仅在作品完整下载成功、校验有效且非空时生成新的元数据 JSON。

### 视频转音频

- **本地音轨提取**：从本地存储挑选常见格式视频文件，快速分离并提取音频流。
- **丰富格式与参数支持**：支持导出为 MP3、AAC、OGG、WAV、FLAC 格式；有损编码格式支持自选码率（最高 320 kbps），无损格式自动保持原生采样规格。
- **便捷流程**：自动持久化记住上次选定的导出目录，界面显示实时转换百分比与进度，支持随时取消；提取完成后提供直接定位或一键加入媒体库播放。

### 后台播放与系统稳定性

- **原生系统级媒体会话**：底层基于 Android `MediaSessionService` 与 Media3 / ExoPlayer 构建，严格遵守 Android 现代前台媒体服务架构规范。
- **通知栏与锁屏联动**：常驻媒体通知栏控制、系统锁屏画报与按键控制与应用内部状态严格保持双向同步；系统语言原生支持简体中文、英文与日文。
- **硬件电源与网络唤醒锁**：播放期间按需持有 CPU WakeLock 与 Wi-Fi Lock，确保设备在长时间息屏与待机状态下音频稳定输出不被系统冻结。
- **播放异常恢复窗口**：遇到短暂网络重连、I/O 读写抖动或 AudioTrack 硬件通道断开时，内置 10 分钟退避恢复窗口自动重试；网络恢复连接或用户点亮屏幕时立即执行优先唤醒尝试。
- **国内定制系统保活提示**：内置进程被杀原因分析；检测到 vivo / OriginOS 等定制系统因高耗电或后台清理导致进程异常终止时，主动弹窗提示用户前往系统设置加入后台白名单。
- **定时睡眠与定时唤醒**：
  - 睡眠定时器支持按倒计时计时，或设定为“当前曲目播完后停止”。
  - 停止前支持音量平滑线性淡出，避免突兀静音惊醒睡眠。
  - 支持定时暂停后于预设时间自动恢复播放。
- **系统精确闹钟与开机保持**：基于 `SCHEDULE_EXACT_ALARM` 与 `RECEIVE_BOOT_COMPLETED`，设备重启后自动恢复尚未完成的定时暂停与自动恢复任务。

### 个性化、系统设置与数据维护

- **主题与视觉个性化**：
  - 提供跟随系统、浅色模式与深色模式切换。
  - 自选应用全局主题色；应用自适应桌面图标与播放控制通知图标颜色同步所选主题色彩。
  - 提供“ASMR.ONE 独立配色”开关：开启后可单独为在线模块设置独立主题色，深浅色界面自动根据主色调平滑适配。
  - 基于 ThemeProvider 实现主题全局动态热响应，更改颜色或暗色模式即刻重绘生效，无需重启应用。
- **交互与手势体验**：
  - 底部导航栏支持左右滑动手势无缝切换页面，支持 350ms 长按图标快速复位与切换。
  - 可自选应用启动时默认展示的首页（ASMR.ONE / 本地音频库 / 播放列表）。
  - 设置页面提供粘性分类标题（Sticky Section Headers），长列表滑动定位清晰明了。
  - 内联权限状态卡片：存储访问、通知发送、系统悬浮窗、精确闹钟、安装未知应用等权限状态在设置页集中卡片化展示，并可一键跳转授权。
  - 支持转场动效降速或开启“减少动画”、界面背景毛玻璃虚化开关、高斯模糊度与封面图像解码质量配置。
- **音频焦点与中断行为精细定制**：
  - 细分耳机拔出/蓝牙断开、短暂音频焦点丢失（如地图导航播报）、通话呼入结束后的应对行为（继续播放、暂停、压低音量）。
  - 音频焦点策略支持“标准模式”（独占焦点）与“与其他应用混音模式”（并发发声，不争抢第三方音视频焦点）。
- **数据安全与无损备份 (`.dabackup`)**：
  - 支持将媒体库数据库、用户偏好配置、播放历史/会话与 ASMR.ONE 账号凭据流式导出为标准的 `.dabackup` 文件。
  - 恢复导入流程包含严密的格式校验，在下一次冷启动时以事务级原子替换；若校验或替换失败自动平滑回滚至原有数据，保障本地数据零损坏。
- **存储分析与精细缓存清理**：
  - 存储空间可视化图表：直观划分本地音频文件、封面缓存、ASMR 缓存、日志及系统其他存储占用。
  - 独立缓存清理面板：支持分别清理图片封面缓存、ASMR.ONE 播放缓存、视频抽帧缓存、下载临时分块文件与更新安装包。
  - 隐私脱敏诊断报告：一键导出剔除敏感账号信息的系统环境与运行日志，方便提交 Issue 反馈故障。

DoujinAudio-android-x64-<tag>.apk.sha256
```

- 应用内置更新检测组件，启动时自动或在设置页手动请求 GitHub Latest Release 接口。
- 根据设备底层 CPU ABI 架构智能匹配下载对应的 arm64、armv7 或 x64 APK（无法确定架构时自动回退至 universal 通用包）。
- 下载期间在应用顶栏全局展示下载进度与网络状态；下载完成后严格进行 SHA-256 校验，校验通过后再调起系统安装器执行更新。

## 代码结构

- `lib/app`：应用入口与全局装配层，负责依赖图注入、路由、主题状态、多语言本地化与应用级控制器。
- `lib/core`：通用核心支撑层，包含 SQLite 关系型持久化、平台通信网关（MethodChannel）、共享媒体领域模型与通用 UI 组件。
- `lib/features`：业务功能特性模块，遵循 `domain` / `application` / `presentation` 严格分层：
  - `library`：本地媒体库索引、SAF 授权目录扫描、封面提取与缓存、元数据编辑与 DLsite 在线匹配。
  - `player`：多会话播放管理、队列调度、传输控制、DSP 音频调音台、时间轴与悬浮字幕。
  - `asmr`：ASMR.ONE 远程作品库浏览、账户同步、流式播放与高可靠下载器。
  - `settings`：全局偏好设置、外观定制、内联权限卡片与 GitHub 自动更新。
  - `data_support`：存储空间分析、精细缓存清理、脱敏诊断报告与 `.dabackup` 备份/恢复。
  - `video_converter`：本地视频提取音轨与格式编码转换。
- `android/`：Android 原生层代码，按功能包严格隔离：
  - `player/`：基于 Media3 / ExoPlayer 的 `NativePlaybackService` 前台媒体服务、锁屏通知栏会话、AudioFocus 控制与硬件音效。
  - `channel/`、`scanner/`、`storage/`、`metadata/`、`subtitle/`、`update/`、`common/`：分别负责 Platform Channel 通信、分块流式扫描、SAF 存储、元数据提取、系统悬浮字幕与更新包安装。

## Android 权限

| 权限 | 用途说明 |
|---|---|
| `READ_MEDIA_AUDIO` / `READ_EXTERNAL_STORAGE` | 兼容直接文件系统扫描与传统文件选择路径 |
| `MANAGE_EXTERNAL_STORAGE` | 可选的完整存储管理权限（使用 SAF 系统选择器时无需此权限） |
| `POST_NOTIFICATIONS` | 显示播放控制通知栏常驻卡片、下载进度与关键状态提醒 |
| `FOREGROUND_SERVICE_MEDIA_PLAYBACK` / `WAKE_LOCK` | 支持后台与息屏状态下音频持续播放 |
| `SYSTEM_ALERT_WINDOW` | 在其他第三方应用界面上方悬浮显示全局字幕 |
| `SCHEDULE_EXACT_ALARM` / `RECEIVE_BOOT_COMPLETED` | 实现高精度睡眠定时停止、次日定时自动恢复与设备重启后状态维系 |
| `REQUEST_INSTALL_PACKAGES` | 允许应用内自动下载 GitHub Release 安装包后发起系统更新 |
| `INTERNET` | 用于 ASMR.ONE 在线资源加载、DLsite 元数据检索与 GitHub 更新检测 |

### Android Release 构建

正式 Release 构建必须配置签名信息。缺少 `android/key.properties` 或对应 keystore 时构建会立即终止，不会回退至 debug 不安全签名。

flutter build apk --release --split-per-abi --target-platform android-arm,android-arm64,android-x64 --obfuscate --split-debug-info=build/app/outputs/symbols
```

## 发布流程

向仓库推送与 `pubspec.yaml` 版本严格一致的 Git Tag 会触发 GitHub Actions 流水线：

1. 执行静态代码分析（flutter analyze）、全量 Flutter 测试、Android JVM 测试与 Debug APK 验证构建。
2. 调用仓库 Secrets 中的正式发布密钥构建 Android universal、arm64、armv7 与 x64 四种 APK 安装包。
3. 为所有构建产物生成 `.sha256` 校验和，逐个检验 APK 签名完整性与 CPU ABI 架构匹配度，随后上传为 CI Artifacts。
4. 构建步骤全部成功后创建 Draft 草稿 Release，核实资产完整无误后，正式公开为 GitHub Latest Release。

```powershell
$tag = dart tool/verify_release.dart --print-tag
dart run tool/verify_release.dart --tag $tag
git tag $tag
git push origin main $tag
```
