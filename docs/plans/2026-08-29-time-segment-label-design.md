# 时间段标签即时保存设计

## 目标

修复时间段标签使用过期播放位置的问题；新标签按当前界面语言生成连续默认名称，并在起点、终点均有效后立即通过现有持久化入口保存。

## 方案

- 页面点击“起点”或“终点”时，通过现有 `PlaybackFacade.sessionById` 读取运行时最新位置，回退到详情快照位置。
- 新建草稿时使用本地化模板生成默认名称，从当前标签数量加一开始并跳过重名。
- 保留现有 `_trySaveSegmentDraft` 保存队列：单个端点只更新草稿；第二个有效端点确定后立即保存；后续改名继续防抖保存。
- 不修改标签实体、数据库 schema 或原生播放代码。

## 多语言

- 中文：`标签{index}`
- English：`Label {index}`
- 日本語：`ラベル{index}`

## 测试

- 验证三种语言的默认名称模板。
- Widget 回归测试覆盖：进入详情后播放位置变化、点击端点立即显示最新位置、两个端点完成后数据库出现默认命名标签。
